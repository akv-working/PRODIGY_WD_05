# PRODIGY_WD_05 - Weather App 🌦️

This is Task 5 of my Web Development Internship.  
It’s a responsive weather application built with **HTML, CSS, and JavaScript**, using the [OpenWeather API](https://openweathermap.org/api).

---

## 🚀 Features
- Search weather by city name
- Auto-detect user location with Geolocation
- Switch between Celsius (°C) and Fahrenheit (°F)
- Displays temperature, condition, humidity, and wind speed
- Responsive and clean UI design

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API
